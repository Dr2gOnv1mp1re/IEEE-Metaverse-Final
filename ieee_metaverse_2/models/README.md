# 3D Robot Models Directory

This directory is designated for 3D robot models and components (GLB / GLTF / OBJ / FBX formats) to be integrated by **Member 2 (Robot Models and Component Management)**.

### Guidelines for 3D Models:
- Recommended format: `.glb` (binary glTF) with embedded textures or low-poly vertex colors.
- Maintain a real-world scale (1 unit = 1 meter) consistent with the laboratory environment.
- The assembly workspace flat surface is at `y = 1.01` on top of the workbench.
